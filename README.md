# Thought Garden（thoughtgarden）

疑問・仮説・メモ・気づきといった「思考のノード」を記録し、ノード同士のつながりを線で結んだグラフで眺める思考整理アプリです。「第1回 GitHub新規開発案・三人討論会」で出た案をもとに作りました。

## 機能

- **ノード登録**：タイトル（必須）、種別（疑問／仮説／メモ／気づき）、本文（任意）を登録できます。一覧から削除もできます（削除すると、そのノードに結ばれたリンクも一緒に消えます）。
- **リンクの登録**：ノード同士を関連づけるリンク（ラベル任意）を登録・削除できます。自分自身へのリンクと、すでにある組み合わせの重複リンク（向きを逆にしたものも含む）は登録されません。
- **思考グラフ**：サーバー側で SVG を生成します。ノードを円周上に配置し、リンクのあるノード同士を線で結び、線の近くにラベルを表示します。ノードは種別ごとに色分けされます。外部 JS ライブラリは使いません。
- ユーザー入力（タイトル・本文・ラベル）は HTML エスケープして表示します（SVG 内のテキストも同様です）。

データは SQLite に保存します。DB のパスは環境変数 `THOUGHTGARDEN_DB` で変更できます。

## 使い方

1. 「ノードを追加」フォームで、疑問や仮説などのタイトルと種別を登録します（本文は任意）。
2. ノードが2件以上になったら、「リンクを追加」フォームで関連するノード同士を結びます（ラベルは任意）。
3. トップページの思考グラフと、ノード一覧・リンク一覧で全体を眺めます。
4. 不要になったノードやリンクは、一覧の「削除」ボタンから消せます。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- ログイン機能はありません。
- Render 無料プランでは SQLite のデータが再デプロイ等で消える場合があります。大事な思考の記録は手元にも控えを残してください。
- グラフのレイアウトは円形配置のみです。ノードが多いとタイトルやラベルが重なって見づらくなることがあります。
